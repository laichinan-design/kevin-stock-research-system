## 使用例子
- 完整研究 TWSE:2330，建立獨立資料夾，採半導體模板；沒有模型就先交付公司研究。
- 比較兩檔已研究股票，核對EPS口徑、期間與幣別，列不可比較項。
- 用指定Excel更新這檔股票，先核對股票鍵、欄位及原檔指紋。
- 對追蹤清單計算合併資金方案，不要重複使用現金。
- 用Kevin雙層錨定估值這檔股票：潛力股錨定、列出非經常性項目，並並列情境A／B。
